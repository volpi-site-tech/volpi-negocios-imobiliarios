# Volpi - Site final (Completo)

Estrutura pronta para deploy (Vercel / Netlify).

- Home (curta) com subtítulo em verde premium.
- Página /sobre com texto institucional completo e foto.
- Catálogo dinâmico via data.json (edite sem programar).
- Cada imóvel tem galeria de até 20 imagens (substitua images/gallery_*.jpg).

Para atualizar fotos:
- Substitua os arquivos em images/ com suas fotos (mesmos nomes) ou atualize data.json.

Deploy:
- Envie a pasta para um repositório GitHub e conecte ao Vercel ou envie o diretório direto ao host estático.
